💳 KPay / Wave ဝင်ထွက်

📦 ပစ္စည်းအဝင် / အထွက်နှင့် ငွေတန်ဖိုး

🗓️ ကာလအလိုက် အသေးစိတ်

အသားတင်အမြတ် = အရောင်း − ကုန်ရင်း + KPay/Wave ဝန်ဆောင်ခ − အသုံးစရိတ်။ ငွေသွင်း/ထုတ် မူရင်းငွေကို အမြတ်အဖြစ် မတွက်ပါ။ အမြတ်သည် အရောင်းမှတ်တမ်းတွင် သိမ်းထားသော ကုန်ရင်းဈေးနှုန်းအပေါ် မူတည်သည်။ အဟောင်း Stock မှတ်တမ်းများတွင် ငွေတန်ဖိုးမရှိပါက လက်ရှိပစ္စည်းဈေးနှုန်းဖြင့် ခန့်မှန်းတွက်ချက်နိုင်သည်။

🧾 အရောင်းမှတ်တမ်း

🗑 အဖျက်မှတ်တမ်း

မှတ်တမ်းတစ်ခုချင်း ဖျက်နိုင်သလို အားလုံးကိုလည်း ဖျက်နိုင်ပါတယ်။ ပြန်ယူလိုသည့်မှတ်တမ်းကို အရင်ပြန်ယူပါ။

☁ Appwrite Cloud သိမ်းဆည်း / ပြန်ယူခြင်း

Login ဝင်ထားပါက Data အားလုံး Auto Sync လုပ်ပေးသည်။ လိုအပ်ပါက အောက်ပါ Manual Backup / Restore ကိုလည်း အသုံးပြုနိုင်သည်။

Cloud မချိတ်ဆက်ရသေးပါ

ဖုန်းအားလုံးတွင် ဆိုင်အကောင့်တစ်ခုတည်း Login ဝင်ပါ။ Auto Sync နှင့် Manual Backup / Restore နှစ်မျိုးလုံး အသုံးပြုနိုင်သည်။

Cloud မှ လဖျက်ပြီးနောက် Sync မလုပ်တော့ပါက ဤခလုတ်ကို ဖုန်းနှစ်လုံးလုံးတွင် တစ်ကြိမ်နှိပ်ပါ။ Local Data ကို မဖျက်ဘဲ ID အလိုက် ပေါင်းစည်းပြီး Cloud သို့ ပြန်တင်ပေးမည်။

🗑 Cloud ထဲက မှတ်တမ်းဖျက်ရန်

အောက်က လရွေးပြီး ခလုတ်နှိပ်ပါ။ ဖျက်တာက Cloud ထဲကရွေးထားတဲ့လကိုပဲ သက်ရောက်ပါတယ်။

Cloud မှ ဖျက်ခြင်းသည် ဖုန်းဒေတာနှင့် JSON Backup ကို မဖျက်ပါ။

💾 Backup / Restore

ကုန်ပစ္စည်း၊ အရောင်း၊ အကြွေး၊ အသုံးစရိတ်နဲ့ မှတ်တမ်းအားလုံးကို JSON ဖိုင်အဖြစ် သိမ်းနိုင်ပါတယ်။

📄 ဖိုင်မရွေးရသေးပါ

အရေးကြီးသောဒေတာများကို ပုံမှန် Backup လုပ်ထားပါ။ Restore လုပ်ခြင်းက လက်ရှိဒေတာကို အစားထိုးမည်ဖြစ်သောကြောင့် မူလ Backup ကို အရင်သိမ်းထားပါ။

ဒေတာအခြေအနေ

ဤလုပ်ဆောင်ချက်ကို ပြန်လည်ပြင်ဆင်၍ မရနိုင်ပါ။

⚙ ဆိုင်ဆက်တင်

ခလုတ်များကို နှိပ်တိုင်း အသံပိုကျယ်ပြီး အနည်းငယ်ကြာကြာ ထွက်မည်။

ကွန်ပျူတာတွင် Thermal Printer ကို Default Printer အဖြစ်ရွေးထားပါ။ ဖုန်းတွင် Browser/Print service က ပံ့ပိုးသည့် Printer ကိုရွေးပါ။

🧹 Local Data ရှင်းရန်

ဒီစက်ထဲမှ ပစ္စည်း၊ အသုံးစရိတ်၊ KPay/Wave၊ Supplier အကြွေးနှင့် Stock မှတ်တမ်းများကို ရှင်းမည်။ အရောင်းစာရင်း၊ အဖျက်မှတ်တမ်းနှင့် Cloud Data ကို မဖျက်ပါ။

စနစ်အချက်အလက်

ဤ HTML ဗားရှင်းသည် လက်ရှိစက်၏ Browser Local Storage တွင် ဒေတာသိမ်းဆည်းသည်။

ဖုန်းနှစ်လုံးတွင် Appwrite ဆိုင်အကောင့်တစ်ခုတည်း Login ဝင်ထားပါက ပစ္စည်း၊ အရောင်း၊ အသုံးစရိတ်၊ အကြွေး၊ Wallet နှင့် Stock မှတ်တမ်းများကို Auto Sync လုပ်ပေးသည်။ Internet မရှိချိန်တွင် Local Data ကို ဆက်သိမ်းထားပြီး ပြန်ချိတ်ဆက်သည့်အခါ Sync ပြန်လုပ်မည်။
